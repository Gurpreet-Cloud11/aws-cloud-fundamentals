AWS Cloud Fundamentals
This repository contains the AWS projects I've completed through NextWork to get more hands-on experience with cloud services, security and how AWS resources work together.

I completed the S3 and IAM exercises in independent mode, so I worked through the tasks without NextWork's guided write-up. I've kept the documentation short and focused on what each project covers, how it works and what I took away from it.
Projects
Project	What it covers
[01 — Host a Static Website with S3](./01-s3-static-website/)	S3 buckets, static website hosting, object permissions and public access.
[02 — IAM Access Control with EC2](./02-iam-access-control/)	EC2 development and production environments, resource tags, IAM users and groups, and tag-based access control.


Why I did these projects
I've mainly been working with Azure, so I wanted to get familiar with AWS as well. These labs helped me see how AWS handles storage and permissions, and how the same cloud concepts apply across different platforms.

The S3 project focused on making website files available through a static hosting endpoint. The IAM project focused on something different: controlling who can do what in an AWS environment, particularly when development and production resources need to be kept separate.
What's next
I'm planning to build on these fundamentals with AWS networking and Terraform, so I can move from configuring individual resources towards deploying infrastructure through code.
